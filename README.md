Node.js User Management API
This is a Node.js application that provides user management functionality, including user registration, login, user listing and role-based access control using JWT.

Requirements
Node.js (version >= 16.0.0)
MySQL (or MySQL-compatible database)
Installation & Setup
Clone the repository:

git clone https://github.com/rhk0/ownAIabackend.git
cd ownAIabackend

Install dependencies: Run the following command to install the required Node.js packages:
npm install

Create MySQL database: Create a MySQL database named db:
CREATE DATABASE db;

Start the server: Run the following command to start the development server:
npm run dev
